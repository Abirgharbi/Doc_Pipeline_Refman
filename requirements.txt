# ── GPU acceleration for Docling (optional but strongly recommended) ──────────
# Docling uses PyTorch internally for layout detection and OCR models.
# Without a CUDA-enabled torch, it falls back to CPU automatically.
#
# Install PyTorch with CUDA 12.1 (most common):
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
#
# Install PyTorch with CUDA 11.8:
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118
#
# CPU-only (no GPU, slower):
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#
# Check your CUDA version first:  nvidia-smi
# Then pick the matching index URL from: https://pytorch.org/get-started/locally/
